Política de privacidad

Última actualización: 18 de noviembre de 2026.

Quién la usa

Segundo Cerebro TaskNotes es una aplicación personal. La usa una sola persona, su propietario, con su propia cuenta de Google. No tiene otros usuarios.

Qué datos de Google usa

Con el permiso que el propietario concede al conectar su cuenta, la aplicación lee y modifica eventos de su Google Calendar para mostrarlos junto a sus notas y tareas, y para registrar en el calendario actividades que él mismo indica.

Dónde se guardan

Los datos se procesan y se guardan solo en el ordenador del propietario, en sus notas de Obsidian. Los permisos de acceso se guardan cifrados en ese mismo ordenador.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad. Cuando el propietario pide ayuda a un asistente de inteligencia artificial que él mismo utiliza, ese asistente puede leer los eventos necesarios para responderle.

Uso de datos de las API de Google

El uso que hace la aplicación de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
